# BudgetBasics React

React/Vite conversion of the BudgetBasics vanilla HTML experience.

Included functionality:
- Responsive header and Savings Goals dropdown
- Hero section and smooth anchor navigation
- Goal Calculator with live sliders, funding ring, calculations, timeline, motivation states and completion confetti
- Expense Planner with validation, add/edit/delete/clear, budget tracking and dynamic tips
- Money Mistakes flashcard deck with 3D flip, shuffle and auto-play/pause
- Scroll progress bar and reveal-on-scroll animations
- Responsive mobile layout

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
